OpportunityTrack Final Professional / AdSense-oriented update

Implemented:
- Automatic official-page image detection: JSON-LD image, og:image, twitter:image, image_src, and a suitable large content image.
- Automatic direct application route detection: Apply Now / Application Portal links and application forms.
- Official information page is never substituted for the direct Apply button.
- Manual image/apply URL fields moved under Advanced overrides because normal imports auto-fill them.
- Every post has an image: source image when suitable, otherwise a unique on-site OpportunityTrack SVG poster generated from the post title/category/provider.
- Broken external images fall back to the generated post poster.
- Public card images use no-referrer where practical.
- Opportunity detail hero redesigned with a large professional image/poster, key details and clear CTAs.
- Homepage plain long-text area redesigned into an original workflow visual plus four readable application steps.
- Public floating Admin button removed; admin remains available at /admin-login.
- Generic navigation records such as Finding Scholarships, Scholarship Database, Find Funding and similar search/navigation titles are blocked/cleaned.
- Public duplicate cards are deduplicated by title + organization + category.
- About page expanded with editorial review/source verification explanation.
- FAQ expanded to state that detected opportunities are not published automatically without review.
- Privacy Policy expanded for remote provider-hosted images and technical request information.
- Existing Cloudflare clean URL behavior kept; no redirect-loop rule added.
- Existing D1 DB and binding name DB remain compatible.

Important:
Google AdSense approval cannot be guaranteed by source code alone. Live site quality, CMP/consent configuration where required, domain history, traffic, content review, and Google's own review remain external factors.
